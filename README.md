# XR Remote Controller 
XR Remote Controller is a small VR simulator where you use the controls to move a toy airplane. The goal is to learn how these controls work. These controls (levers, joystick, dial, knob and slider) are for future projects, like construction simulators or airplane simulators.

## How it works
1. Insert the battery in its socket.
2. Turn it on with the lever.
3. Use all the controls to move the airplane.

## Controls
| Control | Action |
|---|---|
| Battery | Powers all the controls |
| Lever | Turns the control panel on and off |
| Joystick | Moves the airplane |
| Dial | Changes the height of the airplane |
| Knob | Rotates the airplane |
| Slider | Changes the speed of the airplane |

## Built with
- Unity 6.3 LTS
- OpenXR
- XR Interaction Toolkit
- XR Interaction Simulator
- Meta Quest 2 / 3
